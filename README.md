# Generador de Diagramas de Gantt

Es una aplicación web diseñada para transformar datos de proyectos almacenados en archivos CSV en diagramas de Gantt interactivos y fáciles de interpretar. La herramienta permite cargar, editar y organizar información de tareas para visualizar cronogramas de manera clara y eficiente.

Su objetivo es simplificar la planificación y el seguimiento de proyectos mediante una representación gráfica del progreso, facilitando la toma de decisiones y la gestión del tiempo.

## Características

* Importación de archivos CSV.
* Edición de datos directamente desde la aplicación.
* Generación automática de diagramas de Gantt.
* Visualización de tareas, responsables y fechas.
* Organización jerárquica de actividades.
* Exportación del diagrama generado.
* Interfaz intuitiva y fácil de usar.
* Adaptación a diferentes estructuras de proyectos.

## Funcionamiento

1. Cargar un archivo CSV con la información del proyecto.
2. Visualizar y editar los datos si es necesario.
3. Procesar la información mediante la aplicación.
4. Generar automáticamente el diagrama de Gantt.
5. Exportar o descargar el resultado para su uso posterior.

## Tecnologías Utilizadas

* HTML5
* CSS3
* JavaScript
* D3.js
* Gestión de archivos CSV

## Requisitos

* Navegador web moderno.
* Archivo CSV con la estructura requerida por la aplicación.

## Uso

1. Abrir la aplicación en el navegador.
2. Seleccionar un archivo CSV.
3. Revisar y modificar la información según sea necesario.
4. Generar el diagrama de Gantt.
5. Exportar o descargar el cronograma generado.

## Objetivos del Proyecto

Proporcionar una solución práctica para la gestión de proyectos que permita importar, organizar y visualizar cronogramas a partir de archivos CSV, mejorando la comprensión del estado de las tareas y apoyando la toma de decisiones basada en información visual.
